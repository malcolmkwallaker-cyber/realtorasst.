Activity Monitor

Track what you do on your computer and phone so Claude can turn it into SOPs for your assistant.

Not recording

The monitor tracks which app and window is active every 5 seconds. No keystrokes or screen content are captured. Data is stored locally in activity.db.

To track phone activity, send a webhook from your phone to this server:

POST http://<your-server-ip>:8000/api/phone/activity

Body (JSON):

{"app_name": "Zillow", "window_title": "Zillow — Search", "duration_sec": 120, "source": "android"}
Android (Tasker):
  1. Create a Profile → Event: App Opened
  2. Task → HTTP Request → POST to the URL above
  3. Body: {"app_name":"%app_name","window_title":"%app_name opened","source":"android"}
iOS (Shortcuts):
  1. Open the Shortcuts app → Automation → New Automation
  2. Trigger: App Opens → select your apps
  3. Action: Get Contents of URL → Method: POST → URL above
  4. Request Body (JSON): {"app_name":"AppName","window_title":"AppName opened","source":"ios"}
